# "MCP-ready" badge

Show that a project has been analyzed with legacy2mcp and has reviewed MCP
tools. The report's appendix prints this snippet with your own numbers filled in.

```markdown
[![MCP-ready](https://img.shields.io/badge/MCP--ready-12%20tools-6f42c1)](https://github.com/OWASP/legacy2mcp)
```

[![MCP-ready](https://img.shields.io/badge/MCP--ready-12%20tools-6f42c1)](https://github.com/OWASP/legacy2mcp)

Replace `12` with the number of tools you actually expose. A variant that shows
the read-only share:

```markdown
[![MCP-ready](https://img.shields.io/badge/MCP--ready-9%20read--only%20%2B%203%20gated-6f42c1)](https://github.com/OWASP/legacy2mcp)
```

The badge is a static shields.io image. It makes no claim beyond what you
put in it, so only add it once you've reviewed the report and generated a
config.
